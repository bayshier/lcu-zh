Updated 2026-09-27. These fixtures used no real model or GUI task.

The latest release targets Linux ARM64, Linux x86-64, and Apple Silicon macOS. See the latest release notes under [docs/releases/](releases/) for the final archive checks and their limits. Historical results below apply only to their recorded source and inputs.
