# LCU 0.6.0

This release fixes setup, doctor, and adapter defects found in a codebase review and adds opt-in memory and `lcu prune`. It adds no new platform or harness verification claims; Windows remains deferred.

## Changes

- **Setup remembers opt-ins.** A successful setup or export saves `{"chrome", "audio"}` per account in `~/.local/state/lcu/setup.json`. Rerunning setup without `--chrome`/`--audio` keeps the saved choices, so adding audio no longer drops Chrome and vice versa. `--no-chrome` and `--no-audio` disable them. A saved choice, including a declined Chrome prompt, suppresses the interactive prompt.
- **`lcu prune [--keep N] [--yes]`** removes superseded releases under `<prefix>/releases` and, on Linux and Windows, unreferenced private app copies under `<prefix>/apps`. It keeps the current release plus the most recent others (default `--keep 2`) and is a dry run without `--yes`.
- **macOS `lcu doctor`** exits 0 when the original provider loads and 2 when it fails. `--check-desktop` still exits nonzero on macOS because permission grants cannot be verified by this check.
- **Installed paths instead of bare `lcu`.** `lcu` is not on `PATH`, so the generated skill, setup hints, and docs name the installed runtime. Running `lcu` interactively in a terminal now explains that it is a stdio MCP server instead of appearing to hang.
- **Skill generation:** fixed a variable-shadowing bug that broke Sky document copies for `%40oai` Windows layouts, and the macOS skill now drops the Linux-only window-ID sentence as intended.
- **Claude Code relay:** a turn re-bound after an aborted call now receives its final `Stop` cleanup; cleanup errors no longer mask the original tool result.
- **Smaller archives:** archives ship only the documentation that shipped docs link to, and every relative document link in the archive resolves.
- **Smaller fixes:** `--list-agents` shows user-only scope for OMP and Hermes; export bootstrap keeps `--audio`; `lcu doctor --help` and `lcu --version` no longer require a valid app; installers report the installed runtime when agent registration fails; an empty `CODEX_HOME` is rejected; `lcu-session` reports an unknown account clearly.
- **Docs:** uninstall steps, consolidated readiness guidance, and historical planning records marked as superseded.

- `tests/run.sh` passed in disposable Linux ARM64 (native) and AMD64 (emulated) containers: 247 Python tests, offline installation from the prepared official-app fixture with acquisition network disabled, agent registration including the new opt-in memory and `--no-audio` case, and the original GTK desktop suite.
- The adapter suite passed 36 tests with 8 environment skips.
- The macOS archive installed with `--offline --runtime-only` into a disposable prefix on Apple Silicon, reusing signed ChatGPT 26.924.22138 (CUA `0.0.24/20260924074400-f52ea85e2a98`) in place. `--version`, `doctor --help`, and `prune` dry-run and deletion passed there. No desktop action, harness session, or Chrome action ran on macOS for this release; earlier macOS evidence is unchanged.
