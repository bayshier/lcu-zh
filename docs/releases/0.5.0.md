# LCU 0.5.0

This release adds native OMP and Hermes setup and fixes Codex CLI progress ordering. It includes the existing 0.4.2 audio opt-in, Pi picker, request metadata, and macOS Stop work, together with the latest committed integration and website verification records. All release work is integrated into `main`.

The three archives were built from commit `4224aac3f93f8a83b6757a1af7b10c4e31b77071`. The release tag also records this verification document and test-runner cleanup changes, which are not part of the curated runtime archive. Each archive contains LCU source and redistributable JavaScript dependencies, requires an already installed official OpenAI desktop app, and includes no OpenAI app or runtime binaries. ## Linux and adapter gates

`tests/run.sh` passed in disposable Linux ARM64 and AMD64 containers: 217 Python tests per architecture, offline installation from the already prepared official-app fixture, agent registration, and the original GTK desktop suite. The desktop suite exercised accessibility, Unicode input, keys, paste, secondary actions, window isolation, an independent save oracle, coordinate fallback, screenshots, errors, persistent state, reset, and timeout recovery. Acquisition network access was disabled for installation and desktop checks.

The packaged adapter suite passed 40 tests with zero failures and three explicit environment skips. It used the archive's dependency tree, source test fixtures, and the installed Pi CLI. The skipped checks require an installed original-CUA command, the Pi installed-package project-command fixture, or Windows. Codex adjacent progress/result ordering and the OMP prompt-array regression passed.

## Earlier harness coverage

OMP 18.4.1 and Hermes v2026.9.24 (CLI 0.21.5) passed real model-directed Linux GTK and Chrome browser save flows with independent file oracles. Their interactive approval matrices passed nine OMP cases and seven Hermes cases. These earlier runs are recorded with their exact source boundaries in [browser verification](../verification/harness-browser-flows-2026-09-28.md), [desktop verification](../verification/harness-desktop-flows-2026-09-28.md), [OMP verification](../verification/omp-compatibility-2026-09-28.md), and [Hermes verification](../verification/hermes-harness-2026-09-28.md). They are not relabeled as tests of the final 0.5.0 archive.

Both harnesses use profile-scoped native registration. Explicit, automatic, and interactive selection reject unsupported project scope before configuration writes. Hermes approval persistence uses the original runtime's offered scopes; a permanent choice is shown only when the original request offers it.

The exact macOS archive installed successfully with `--offline --runtime-only` in the task-owned macOS 26.6.2 ARM64 UTM guest. Independent saved files matched the requested markers. For each harness, the session case selected session approval once.
