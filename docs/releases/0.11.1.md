# LCU 0.11.1

**Pi and OMP no longer start a computer-use host in every session.** A session or subagent that never calls an LCU tool now starts no host at all.

## Changes

- **Pi and OMP start the host on the first LCU tool call.** Pi needs LCU's tool definitions and instructions before its first model call, so the adapter used to start a host in every session and subagent child, even when computer use was never called. After one connect, it now keeps the original `js` and `js_reset` definitions and instructions in memory and in a per-account cache file. Later sessions register them without a host, which starts on the first LCU tool call or `/lcu pick`. `/lcu stop` with no host running no longer starts one ([#38](https://github.com/amontlabs/lcu/issues/38), [#39](https://github.com/amontlabs/lcu/pull/39), thanks @valkyriweb).
- **The cache follows what you installed.** The cache key covers the launch command (including `--user` and `--chrome`), `CUA_REPL_ENABLED_SURFACES` and the other instruction settings, platform, architecture, Pi or OMP, the per-account cache folder, and the installed LCU release, app and runtime versions. A change to any of them connects again. If the host later reports different tools or instructions, the entry is replaced.
- **Live Touch ID check for `lcu cross-turn on`.** The macOS owner prompt that 0.11.0 listed as not verified was checked live and recorded in the [verification record](../verification/cross-turn-2026-10-10.md) ([#40](https://github.com/amontlabs/lcu/pull/40)).

## Behaviour changes to know about

- **A broken host shows up later.** With a cached surface, a host that fails to start is reported at the first LCU tool call instead of at session start. The first tool call also waits for the host to start.
- **Where the cache is not used.** Windows, a launch command LCU cannot identify, and `LCU_SURFACE_CACHE=0` still connect at session start, as before.
- **A new cache file.** Pi and OMP write `pi-surfaces.json`, with a `.lock` beside it, in LCU's per-account cache folder. Deleting it is safe; the next session connects once and records it again.

## Upgrading

Run `lcu update`, then restart your agents. Your agent registrations and saved choices carry over. To go back, reinstall 0.11.0.
