# LCU 0.11.2

**`js_reset` no longer leaves Computer Use's keyboard taps behind on macOS.** After a reset, the Codex Computer Use service could keep its focus-enforcer event taps until it exited. Once, that doubled every keystroke system-wide.

## Changes

- **Turns end before `js_reset` (all agents).** `js_reset` stops the original worker that holds each turn's turn-ended hook, so turn ends after a reset reached nothing and the service kept its taps. Before forwarding `js_reset`, the Claude, Codex and Pi/OMP/Hermes relays now end every turn that ran `js` on that worker. The turn then continues under a fresh id, so its later calls still work. A live run on Calculator showed the taps removed at the reset and the turn still working ([record](../verification/sky-event-taps-js-reset-2026-10-10.md)).
- **Cleanup at exit (macOS).** When the LCU host stops, it now sends the original turn-ended signal for any turn that never got one, waiting at most 8 seconds.
- **Diagnostics say whether a turn end reached Computer Use.** `turn_end` events in the diagnostic log now carry `sky_hook`: `live`, `reset` or `none`. Ends sent before a reset are logged with `cause: "js_reset"`. The Codex relay now logs its turn ends too.

## Behaviour changes to know about

- **A reset ends the turn for Computer Use, briefly.** Apps the turn was controlling get the same cleanup as at a turn's end, then the next call starts again. Call `get_app_state` before acting after a reset, as at the start of a turn.
- **Exit can take a little longer on macOS.** It takes up to 8 seconds, and only when a turn was still open.

## Upgrading

Run `lcu update`, then restart your agents. Your agent registrations and saved choices carry over. To go back, reinstall 0.11.1.
