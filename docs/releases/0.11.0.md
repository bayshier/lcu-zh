# LCU 0.11.0

**Claude Code subagents no longer cut off their parent's Computer Use, and an opt-in setting keeps it available across turns.** A foreground subagent finishing used to make the parent's next call fail with "Computer Use is unavailable because the current turn ended." That no longer happens.

## Changes

- **A subagent finishing no longer ends its parent's turn (Claude Code).** Claude Code subagents share their parent's prompt id, which the relay used as the turn id the original service sees, and the service ends turns by id. Each subagent now has its own turn id, so its end affects only itself. This is always on.
- **`lcu cross-turn`, an opt-in setting (Claude Code).** `lcu cross-turn [status|on|off] [--json] [--unattended]` keeps Computer Use available to every turn of a session, including background subagents still working after the turn that started them ended and a turn that reuses an ended turn id. It is off by default; with it off, Computer Use ends with each turn as before. The setting is read on each turn, so running sessions pick it up without a restart.
- **`lcu setup --cross-turn on|off [--unattended]`.** Interactive setup asks once when nothing is stored. The Linux and macOS installer forwards both options (and rejects them with `--runtime-only`); the Windows installer does not accept them, so on Windows use the installed `lcu setup` or `lcu cross-turn`. `lcu status --json` reports `cross_turn`.

## Behaviour changes to know about

- **Off by default.** Nothing changes for a background subagent after a turn ends until you turn it on. The setting affects only the Claude Code relay; other agents ignore it.
- **Turning it on asks on macOS.** `lcu cross-turn on` asks for Touch ID or your login password, as `lcu apps allow` does. `off` never asks. Linux and Windows have no owner prompt.
- **A guard against accidents, not a security boundary.** Anything running as your account can edit `~/.local/state/lcu/cross-turn.json` (Windows: `%USERPROFILE%\AppData\Local\LCU\cross-turn.json`) or pass `--unattended`.
- **Per-app approvals still apply** on macOS and Windows; the Linux runtime has none. Your harness's tool approvals are unchanged.
- **Sandbox VMs.** On disposable machines provisioned without a person, use `lcu setup ... --cross-turn on --unattended`, which skips the owner prompt and records `unattended`.
- **Limits.** The Claude relay allows 1024 live turns at once and remembers 65,536 ended keys and closed prompts; for an extremely old one it falls back to the earlier behavior. See [Claude turn identity](../ADAPTERS.md#claude-turn-identity-and-cross-turn-computer-use) and the [verification record](../verification/cross-turn-2026-10-10.md), which lists what was not verified (the live Touch ID prompt, the interactive Claude Code UI and desktop app, Linux and Windows desktops).

## Upgrading

Run `lcu update`, then restart your agents. Your agent registrations and saved choices carry over, and cross-turn stays off until you turn it on. To go back, reinstall 0.10.1.
