# Original instruction delivery

LCU gives the model the same instructions as official Codex computer use, through the same channel. Official Codex wires computer use through the bundled `unified-computer-use` plugin, which contains only the original `cua_repl` MCP server and its lifecycle hooks: no skill and no documents for the model to read. The model receives the original MCP initialization instructions, the `js` and `js_reset` tool descriptions and schemas, and the guidance the runtime returns in tool results, including the complete first-call guide and confirmation policy. The original app also suppresses legacy computer-use plugin skills for surfaces the unified runtime handles, to avoid conflicting instructions (`Gi`/`Pre` in the [host inventory](HOST-INVENTORY.md)).

LCU launches that same original server from the selected app and forwards those instructions unchanged. On macOS with ChatGPT 26.928.20755, the initialization instructions and the first-call guide returned by `await cua.getState()` were byte-identical between the official plugin server and both LCU relays (Codex and Claude Code). The `js` description differed only in its browser section, because LCU's default surface is computer-only. Pi and OMP add the original initialization instructions to their system prompt (Pi appends them to `systemPromptOptions.appendSystemPrompt` when the host provides it, so its structured prompt and prompt cache stay intact; otherwise they are appended to the prompt itself); Hermes injects the original initialization instructions and public tool descriptors each turn.

LCU registers no skill, matching the official plugin. Setup also removes the `lcu` skill that earlier LCU versions registered in each harness, and the copy they generated under `~/.local/share/lcu/skills`. Portable exports contain no skill and resolve the original application on the destination machine.

The original launcher selects its dynamic instructions through `process.platform` and `CUA_REPL_ENABLED_SURFACES`. Default `lcu` selects the computer surface; `lcu --chrome` selects browser and computer, and the runtime then returns the original browser guidance. After context compaction, the original tool description tells the model to call `cua.rewriteDocumentation()`.

Earlier LCU versions registered an LCU-authored `lcu` skill that required reading copied guides before the first call. Neither the skill nor that step has a counterpart in official Codex; in a 2026-10-01 benchmark, Codex with LCU spent its first action trying to open the skill file even after the reading step was removed. Both were removed. The source repository's historical `scripts/instructions.lock.json` records the original resources of the former full-bundle candidate; it is a historical baseline, not release payload.
