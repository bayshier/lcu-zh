LCU

Codex computer use, decoupled from the Codex app.

Give Claude Code, Codex CLI or Pi the original computer-use runtime from the ChatGPT desktop app, with no Codex sign-in. The app stays installed on your machine and supplies the runtime; LCU handles setup and harness integration.

LCU checks the installed app for compatibility and runs its original computer-use runtime. Instructions, tool results and approval requests pass through unchanged. Your harness forwards them to the model and cleans up when each turn ends.

No sign-in

✓ No Codex sign-in required

Uses the app you have.

LCU never downloads or installs the ChatGPT app, and doesn’t need you to sign in to it.

Original runtime

Nothing reimplemented.

LCU doesn’t implement browser control, screenshots, accessibility or input. It runs the original runtime, keeps the original instructions byte-for-byte, and preserves the original approval prompts.

Install

One prompt. That’s it.

Copy this into your agent. It checks your OS, architecture and prerequisites, installs the latest release, and guides you through any permissions.

Tell your agent 
Install and configure LCU for this harness using the latest release.
Follow https://raw.githubusercontent.com/amontlabs/lcu/main/docs/INSTALLATION.md
Check my OS, architecture, and prerequisites, then guide me through any required permissions.

Then restart your harness, ask it to use LCU to take a screenshot of a harmless window, and approve the request. That’s the first check that everything works.

Requirements

What you need, plainly.

Before you install

  • The official ChatGPT desktop app. It supplies the runtime and instructions. Download it from OpenAI; LCU never installs it for you.
  • Python 3.12+.
  • Your harness: Claude Code, Codex CLI or Pi, installed and signed in.
  • Codex CLI users: update before setup to get the required mcp_tool hook support.
